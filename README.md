# 🤖 AI Voice Recruiter

An AI-powered mock interview application that helps candidates practice interviews using voice-based interactions and receive AI-generated feedback.

## Features
- Voice-based interview practice
- Speech recognition
- AI-powered feedback
- Interview activity monitoring
- Interview performance review

## Technologies Used
- Python
- FastAPI
- HTML, CSS, JavaScript
- Google Gemini API

## Run Locally
```bash
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```
